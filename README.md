# YouTube Play Assist

YouTubeの動画プレーヤーの標準操作バーに再生支援ボタンを追加するChrome拡張（Manifest V3）です。
## 操作

- 動画下部の標準操作バー（再生ボタン・音量・再生時間がある場所）に追加されるボタンから操作します。標準の操作バーと一緒に表示・非表示になります。
- 再生速度は0.25〜4倍から選択できます。「1×」で通常速度に戻ります。
- 「↶10」「10↷」で10秒ずつ移動します。動画の先頭・末尾を超えません。移動時は区間ループを解除します。
- 「A↔B」を押すと区間ループの設定が開きます。開始・終了を入力するか、それぞれの「現在位置を設定」を押してから「区間ループ ON」を押します。開始位置に移動し、終了位置で開始位置に戻ります。
- 設定は「×」、Escapeキー、設定の外側のクリック、または「A↔B」の再クリックで閉じられます。閉じてもループは継続し、「A↔B」が緑色になります。
- 時刻は `90`、`1:30`、`1:02:03` などで入力できます。小数秒も入力可能です。「現在位置を設定」は秒単位で切り捨てます。
- 「区間ループ OFF」または「解除」でループを停止します。区間の編集時や別の動画への移動時にも停止します。

通常の動画ページ（`https://www.youtube.com/watch?v=...`）が対象です。全画面でも表示されます。Shorts、埋め込み動画、ライブ配信の区間ループは対象外です。広告中は操作を避けてください。ループにはブラウザのイベント・タイマーを使用するため、終了位置にはわずかな誤差が出る場合があります。
